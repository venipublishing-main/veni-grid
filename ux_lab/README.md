# Veni Grid UX Lab 01

Open [grid-workbench.html](grid-workbench.html) in a browser. It is a standalone, no-server design prototype. It has no school records, no network access, no account login, no solver connection and no data persistence.

Try candidate A/B, perspective selection, timetable zoom, search, selecting a lesson, toggling a local-only lock, and creating a mock independent invigilation draft. The on-screen values 2,900→2,380 are grounded in synthetic Benchmark B scoring evidence, **but the coloured lesson cells are illustrative and not exported from that solver result**.

See [UX design and acceptance test brief](../docs/UX_LAB_01.md). Real student, staff, exam or duty data must never enter this public prototype.
